# onaia.fr — personal academic site

This repository contains a minimal, modern, academic personal website scaffold built with Astro, TypeScript and MDX.

Run locally:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

Notes:
- Content is stored in Astro Content Collections (see `src/content`)
- MDX supports KaTeX via `remark-math` and `rehype-katex`
