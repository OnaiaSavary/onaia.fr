# Comprendre les sécheresses européennes

Une sécheresse ne dépend pas uniquement de la quantité de pluie reçue. Elle résulte d'un déséquilibre entre les précipitations et les pertes d'eau liées à l'évaporation. On peut résumer ce bilan hydrologique avec la relation $D = E - P$, où $D$ représente le déficit, $E$ l'évaporation et $P$ les précipitations.

Lorsque l'atmosphère est durablement organisée dans un même régime de circulation, les conditions météorologiques peuvent rester anormalement sèches pendant plusieurs semaines.

## Un bilan simple

À l'échelle d'un sol, le changement de stock d'eau peut s'écrire :

$$
\Delta S = P - E - R
$$

Ici, $\Delta S$ est la variation de l'eau stockée dans le sol et $R$ représente le ruissellement. Une valeur négative de $\Delta S$ indique que le sol s'assèche.

## Un peu de code LaTeX

La formule précédente est écrite dans le fichier MDX avec le code suivant :

```latex
\\Delta S = P - E - R
```
